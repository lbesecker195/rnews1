罗曼望远镜定于周日发射

宇宙 · 2026年8月29日 · 0 分钟阅读

NASA耗资43亿美元的南希·格蕾丝·罗曼太空望远镜已安装就位，计划于美国东部时间上午7:26、8月30日星期日，在周六发射准备评审之后，从肯尼迪航天中心39A发射台搭乘SpaceX猎鹰重型升空。硬件已经装上火箭，评审也已完成。如果佛罗里达天气和剩余倒计时流程能够顺利进行，时钟如今已指向周日早晨的发射窗口，而航天界早已将这次发射标记为不容错过。

这不是一个搭便车升空的小型载荷。罗曼是一座宽视场红外天文台，是NASA旗舰级天体物理任务，造价43亿美元，搭载在SpaceX现役舰队中最强大的火箭上。猎鹰重型之所以是重型运载火箭，正是因为目的地并非近地轨道。从39A发射台升空后，这座天文台计划巡航约100天前往日地L2点。那里是远超月球轨道之外的引力路径节点，巡天望远镜可以在此获得稳定位置，凝视寒冷而黑暗的天空。

直播于上午6:20开始。天气有利概率接近50%。这两个数字比任何口号都更能说明当天早晨的情况。直播会在美国东部时间上午7:26的发射尝试前一个多小时开始。天气预报胜负各半。一座已经安装就位的望远镜、一次获准进行的发射准备评审，以及五五开的天空，这就是佛罗里达大型发射前夜的真实感受。

周六通过发射准备评审后安装在39A发射台

安装就位是一个处理流程术语，但公众也能理解其含义。它意味着南希·格蕾丝·罗曼太空望远镜已经与猎鹰重型完成集成，而不是仍在洁净室内等待之后再进行连接。对于这一等级的任务而言，安装就位是倒计时成为主角前最后一个重大的机械状态声明。天文台不再是运输途中的载荷，而是肯尼迪航天中心39A发射台上火箭搭载的载荷。

39A发射台就是那片历史悠久的海岸混凝土平台：阿波罗乘员、航天飞机，以及商业航天时代的SpaceX重型运载工具，都曾从这里飞向轨道及更远处。周日的发射尝试使用的是这段历史留下的基础设施，而非怀旧。猎鹰重型是一枚三级芯火箭，罗曼是一座大型红外望远镜。当科学目标是日地L2点，而不是空间站或通信轨位时，这种组合就是一次重型运载发射尝试的真实样貌。

周六发射准备评审是与安装就位相对应的管理流程。发射准备评审是发射管理人员审查运载火箭、载荷、靶场、天气及剩余工作，并决定是否继续发射尝试的会议。评审结果为“可以发射”。这就是为什么公开的时间并非传闻，而是8月30日星期日，美国东部时间上午7:26，直播则已于上午6:20开始。

“可以发射”并不等于保证成功，而是允许在硬件已经完成安装、天气仍需等待观察的情况下进入倒计时。肯尼迪航天中心的8月底正值海风、雷暴和突然暂停频发的季节。评审可以清除文件上的障碍，只有当天早晨才能清除天空中的障碍。

50%的天气预报与上午6:20的直播

天气有利概率接近50%。这个数字不是修辞，而是此次发射尝试所面对的运行现实。接近一半的天气预报意味着，如果佛罗里达在夏末展现其一贯的天气脾气，已经安装就位的天文台仍可能在发射台上等待，直至发射因天气取消。它也意味着这次发射尝试足够接近现实，以至于航天界把周日视为真正的日期，而不是占位符。

直播于上午6:20开始。提前量是NASA和SpaceX发射日流程的一部分。观众、记者以及任务团队自己的支持者，会在美国东部时间上午7:26之前看到火箭状态、天气判断和剩余投票流程。对于从39A发射台发射的猎鹰重型来说，这额外的一小时正是发射准备评审的信心与仅有五成把握的天气预报相遇的时间。

这也是为什么此次发射已经成为航天界的必看事件。一座43亿美元的天文台并不会每月都被运往发射台。将宽视场红外望远镜送往L2的重型运载发射尝试更为罕见。再加上**50%**的天气预报和周日早晨的发射时间，观众不会等到事后看一份新闻稿，而是会提前定好闹钟。

如果天空配合，火箭将点火升空；如果不配合，望远镜仍会保持安装状态，评审中的“可以发射”将变成重新循环，原有硬件等待下一次机会。当前信息没有给出备用日期，只写着周日。周日就是发射尝试日。

配备借用镜面的宽视场红外天文台

罗曼是一座宽视场红外天文台。这四个词概括了任务的科学身份。宽视场意味着它的设计目标是一次观测大面积天空，而不是盯住某一个著名天体。红外意味着它将在这样一个波段工作：遥远星系的光因宇宙膨胀而被拉伸，较冷的天体以及被尘埃遮蔽的结构也能在其中显现。两者结合，描述的是一台巡天机器，而不是一间肖像摄影棚。

这台机器的“眼睛”是一面2.4米镜面，最初为一个被取消的NRO间谍卫星项目建造。NRO是美国国家侦察局，负责运行机密成像卫星的美国机构。为间谍卫星切割的镜面必须足够大、足够坚固，并经过极其精密的成形。项目取消后，这块光学元件并没有失去收集光子的能力，只是失去了原本的工作。NASA的罗曼任务赋予了这套硬件第二次民用生命。

2.4米主镜在尺寸级别上属于哈勃望远镜等级的口径，不过本文不会凭空加入简报未提供的额外比较数字。现有记录提供的是它的来源：一个被取消的侦察项目、一面重新分配用途的镜面，以及一项没有大型现成光学元件就无法实现的宽视场红外任务。间谍卫星的过去并不是笑料，而是这座43亿美元天文台拥有一只可执行飞行任务的眼睛的原因。

红外观测也决定了航天器的热特性。热量就是噪声。地球反照光也是噪声。一台温暖的望远镜无法完成罗曼被派去执行的巡天任务。这是它不前往低轨道的原因之一。它将巡航约100天前往日地L2点，在那里，地球和太阳处于一种特殊的几何关系中，使遮阳罩和稳定的热环境能够完成宽视场红外相机所要求的安静工作。

前往日地L2点约需100天

在猎鹰重型从39A发射台成功升空后，罗曼将巡航约100天前往日地L2点。L2是日地系统的第二拉格朗日点，是远超月球之外的引力平衡区域。前往那里的航天器只需消耗适量燃料进行位置保持，并能让地球和太阳大致处于同一方向，这对红外天文学来说是一份馈赠。天空会保持黑暗，热负荷会保持稳定，巡天可以避免近地轨道中持续的冻融变化。

约100天指的是巡航时间，并不意味着周二就能抵达。周日的重型运载发射尝试是转移过程的开始，而不是科学工作的开始。从发射台到L2之间，还要经历轨道修正点火、展开、检查，以及一段漫长而安静的飞行过程，才能把已经安装的载荷变成在位运行的天文台。管理人员和公众会关注周日，是因为没有发射就没有巡航；而他们还要等待更久，天空才会真正打开。

日地L2点也是猎鹰重型成为运载工具的原因。一座配备2.4米镜面、3亿像素相机、日冕仪载荷、遮阳罩以及远离地球运行所需燃料和系统的宽视场红外天文台，不是顺路搭载的共享载荷，而是重型运载货物。位于肯尼迪航天中心的39A发射台，正是这类SpaceX任务离开佛罗里达的地方。

100天这个数字也为公众预期划定了范围。想在周日看到首批科学图像的人不会如愿。此次发射尝试是发射，巡航需要约100天，调试将在抵达之后进行。按照当前计划，任务预计在2027年初传回图像。

暗能量、暗物质与数千颗系外行星

罗曼将被派去搜寻暗能量、暗物质和数千颗系外行星。这三者浓缩在一句话中，构成了任务的科学目标，也解释了为什么安装在发射台上的是一台巡天望远镜，而不是一台只执行狭窄深场观测的专用设备。

暗能量是对宇宙膨胀加速这一未解现象的称呼。一座宽视场红外天文台可以绘制被宇宙膨胀拉伸了光线的星系的大范围分布图。这些星系的形状、距离和聚集方式，能够帮助宇宙学家检验这种加速究竟像一个常数、像某种随时间演化的因素，还是说明现有模型存在偏差。罗曼的搜寻是统计意义上的搜寻，宽视场是方法，红外是波段。

暗物质是另一种不可见的宇宙主要成分。它不会发光，而是通过引力显现出来：通过质量如何使更遥远星系的光发生弯曲和剪切，以及结构如何在宇宙时间中成长。绘制暗物质分布，需要大规模且均匀的巡天。用于绘制暗能量的同一面2.4米光学镜面和同一台3亿像素相机，也将绘制塑造这些星系的暗物质。

搜寻目标中的行星部分是数千颗系外行星。这并不是声称会发现几颗著名世界，而是一个关于行星总体分布的目标。来自L2的宽阔稳定视野、能够监测密集恒星场的相机，以及可以尝试抑制星光的日冕仪技术演示设备，让一项以宇宙学为卖点的任务同时成为一项行星搜寻任务。记录中的数字是“数千颗”，足以改变行星目录，但不能据此凭空捏造更具体的发现数量。

这三项搜寻都不会在美国东部时间上午7:26发生，而是在巡航、调试以及数据档案开始积累之后进行。周日是闸门，暗能量、暗物质和数千颗系外行星则是这道闸门值得一座43亿美元天文台和一枚猎鹰重型火箭的原因。

3亿像素相机与日冕仪技术演示设备

与此次发射相关的仪器清单简洁而明确：一台3亿像素相机，外加一个日冕仪技术演示设备。

3亿像素焦平面是让宽视场望远镜成为巡天引擎的关键。这里的百万像素并不是智能手机式的炫耀，而是探测器的有效面积，使2.4米镜面能够一次记录大块天空。宇宙学需要样本，行星搜寻需要时间序列，而两者都需要视场。3亿个像素，就是NASA送入太空、用于红外观测工作的相机规模。

日冕仪则是另一类仪器。它会遮挡或抵消恒星刺眼的光芒，使附近微弱的结构——包括从长远看可能存在的行星——能够被记录下来。在罗曼任务中，它被列为技术演示设备，这既是工程术语，也是项目管理术语。技术演示设备被送入太空，是为了验证某种能力，证明能够以未来直接成像行星任务所需的水平控制星光。在现有记录中，它并不是作为主要巡天相机来宣传，而是作为随任务一同飞行的演示设备。

两种仪器共同解释了载荷的特点。3亿像素相机是执行暗能量、暗物质和宽视场系外行星搜寻的主力。日冕仪技术演示设备则是更困难观测的探路者：看清恒星旁边有什么。安装在猎鹰重型上的天文台将同时携带两者。

理解这一组合不需要额外的性能数字，本文也不会凭空添加。简报中的硬件清单就是全部硬件清单：宽视场红外光学系统、一面拥有2.4米口径、继承自NRO项目的镜面、一台3亿像素相机，以及一个日冕仪技术演示设备。

提前近9个月发射，伴随预算风波

管理人员表示，任务将比正式准备就绪日期提前近9个月发射，同时还处于曾经出现取消尝试的长期预算风波之中。这句话构成了任务的政治与进度主线，也说明周日并不是一次普通的旗舰任务发射。

正式准备就绪日期是项目用来衡量进度的官方日历节点。对于一座造价43亿美元的天文台来说，比这一节点提前近9个月发射十分罕见。大型NASA天体物理任务更常见的是延期，而非提前。管理人员的说法是，这次任务正朝相反方向推进：已经安装就位、通过评审，并瞄准8月30日发射，远早于文件中认定其准备就绪的日期。

预算故事与进度加速并存，而不是相互取代。长期预算风波意味着罗曼没有在拨款流程中一路顺利前进。取消尝试意味着这场风波不只是削减某个预算项目，而是曾有人试图终止任务。如今位于39A发射台上的望远镜，是一台挺过这些尝试，并且按照管理人员的说法，比正式准备就绪日期提前近9个月发射的望远镜。

这些风波并不能让我们凭空增加记录中没有提供的官员姓名或投票数字，但它们确实解释了周日气氛的特殊性。一项几乎被取消、如今却提前发射的任务，会让支持者以特别强烈的关注注视猎鹰重型。航天界的必看事件标签不只是因为火箭外形壮观，更因为这是一座43亿美元的天文台，它曾经必须努力争取保住作为载荷的资格。

提前发射仍然不等于提前获得科学成果。这里的“提前”是相对于准备就绪日期而言的发射进度。巡航仍需约100天，首批科学图像仍预计在2027年初获取。这近9个月的提前是地面进度事实，而不是在轨科学事实。

首批科学图像预计于2027年初获取

*首批科学图像预计于2027年初获取。*这是与周日发射、100天巡航以及抵达日地L2点后进行的调试相对应的公开回报时间。

8月30日与2027年初之间的间隔，并不与提前近9个月发射的说法矛盾。提前的说法涉及发射时间相对于正式准备就绪日期的关系；图像的说法涉及天文台抵达L2后，何时能够传回3亿像素相机计划获取的照片和巡天数据。望远镜不会在助推器分离的瞬间打开科学档案，而要在巡航、展开、聚焦、校准，以及在轨掌握日冕仪技术演示设备和宽视场相机之后，才会开始建立数据档案。

因此，2027年初这个日期将发射故事转化为天文学故事。在那之前，罗曼是一艘处于转移和检查阶段的航天器；在那之后，它将成为一座搜寻暗能量、暗物质和数千颗系外行星的宽视场红外天文台。关注周日发射的航天界同时知道这两个时钟。

不要假装首批图像会与直播同时出现，这一点很重要。直播于上午6:20开始。如果天气这项接近50%的因素配合，发射时间是美国东部时间上午7:26。巡航需要约100天，图像则预计在2027年初获取。每个数字都属于不同阶段。把它们混在一起，会让发射日宣传失真；将它们分开，才是43亿美元任务真正的运行方式。

为什么周日是航天界的必看事件

周日的重型运载发射尝试之所以成为航天界的必看事件，是因为故事的每一条线索都同时出现在发射台上。

硬件已经安装就位：NASA的南希·格蕾丝·罗曼太空望远镜，这座造价43亿美元的宽视场红外天文台，正搭载在SpaceX猎鹰重型上，位于肯尼迪航天中心39A发射台。时间已经确定：8月30日星期日，美国东部时间上午7:26，在周六发射准备评审之后发射，直播从上午6:20开始。天气预报很诚实：有利概率接近50%。任务的起源奇特而具体：一面来自被取消的NRO间谍卫星项目的2.4米镜面。轨道旅程漫长：前往日地L2点需要约100天。科学目标指向天空中最重大的未解问题：暗能量、暗物质和数千颗系外行星，使用一台3亿像素相机和一个日冕仪技术演示设备进行搜寻。进度又带有政治色彩：比正式准备就绪日期提前近9个月，同时伴随曾包括取消尝试在内的长期预算风波。首批图像不是周日的图像，而是预计在2027年初获取。

这就是一项完整的旗舰任务，被压缩进佛罗里达的一个早晨。航天界包括需要这项巡天数据的天文学家、让天文台完成安装的工程师、把从39A发射的猎鹰重型视为定点节目观看的发射爱好者，以及多年来听说这架望远镜可能被取消的公众——他们都有理由在上午6:20之前醒来。
